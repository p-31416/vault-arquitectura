# Raw Session — MVP_02 Fuentes Perplexia

## Topics Extraídos

### 1. Comandos AutoCAD (8 clases × 2h)
- Clases: Dibujo, Edición, Annotative, Layers, Blocks, Dimensiones, Plot/Layout, 3D/Salida
- Fuente oficial: Autodesk AutoCAD Command Reference, AutoCAD Help → Shortcut keys
- 30+ comandos por clase listos para mapear a SET-REP/SET-ARQ
- Comandos 3D: _3DORBIT, _PRESSPULL, _EXTRUDE, _SWEEP, _REVOLVE, _SLICE, _SECTIONPLANE, _HIDE, _SHADEMODE, _VISUALSTYLES
- Comandos de automatización: LISP, DIESEL, Action Macro, Script, AutoLISP, .NET API
- ACP exam objectives vinculados a comandos (22%/20%/29%/16%/13% por módulo)

### 2. SETs de Estándares CAD (núcleo + temáticos)
- Principio: núcleo común → SETs específicos por disciplina
- Nomenclatura por prefijo: G- (general), R-/DR- (replanteo), A- (arquitectura), S- (estructura), E- (eléctrica), P- (sanitario), F- (fabricación)
- Cada SET tiene: capas, código de color, linetype, plot style, descripción, ejemplo de uso

### 3. Capas por SET (sistema completo)
- SET-GEN: G-CART (carta), G-MARC (marcos), G-TEXT (texto auxiliar), G-COTA (cotas generales), G-REFE (referencias), G-VPRT (viewports), G-AUXI (auxiliar)
- SET-REP: R-EJES, R-EJAX, R-COTP, R-COTA, R-PTOS, R-NIVE, R-FUND
- SET-ARQ: A-MURO-N/E/D, A-TABI, A-ABER, A-SOLA, A-CIEL, A-ESCA, A-EQUI, A-LOCA, A-SOMB
- SET-EST: S-EJES, S-FUND, S-COLU, S-VIGA, S-LOSA, S-TABI, S-ARMA, S-ESTR, S-META, S-UNIO, S-NIVE, S-DESI
- SET-ELE: E-ILUM, E-TOMA, E-COMA, E-TABL, E-CANA, E-CIRC, E-TEXT
- SET-SAN: P-AFRI, P-ACAL, P-CLOA, P-PLUV, P-ARTE, P-CAMA, P-TANQ
- SET-FAB: F-CORT, F-GRAB, F-PLEG, F-MARC

### 4. Pesos de línea (ISO 128-2)
- 0.13, 0.18, 0.25, 0.35, 0.5, 0.7, 1, 1.4, 2 mm
- Asignación: 0.13-0.25 para detalles, 0.35-0.5 para elementos principales, 0.7-1.4 para bordes/cortes, 2 para títulos

### 5. Equivalencias internacionales
- Studio Pi ↔ NCS ↔ ISO 13567 ↔ AEC UK ↔ ISO 19650
- Tabla de traducción de nombres de capas entre estándares
- Disciplinas: ARCH, STRU, MEP (ELE/SAN), FAB

### 6. MCP Connections
