# FT n01 — Local (LOC)

> **`ft`** = framework técnico. Plan paso a paso para lograr lo que `01-spec-n_01.md` define.

## Fase A — Offset uniforme automático 0.15 ✅

### Algoritmo

```
1. _pline interactiva (usuario dibuja, cierra con C)
    │
2. Calcular centroide de la polilínea
    │
3. Determinar dirección exterior:
   ─ Tomar primer segmento (V0→V1)
   ─ Calcular perpendicular (normal)
   ─ Probar punto a 0.5 m en esa dirección
   ─ Si está más cerca del centroide → invertir normal
    │
4. _offset 0.15 → punto exterior
    │
5. Original se conserva como cara interior
    │
6. Hecho — muro en A-MURO
```

### Comandos AutoCAD utilizados

| Paso | Comando | Argumentos |
|------|---------|------------|
| 1 | `._pline` | Interactivo (pauses hasta `C`) |
| 4 | `._offset` | 0.15, entidad, punto exterior, "" |

### No se necesita

- Explotar la polilínea (el comando `_offset` trabaja sobre la entidad completa)
- Fillet R=0 (el offset de una polilínea cerrada mantiene esquinas limpias automáticamente)

### Verificación — Fase A

- [x] `_pline` interactiva permite clics + `C` para cerrar
- [x] Offset se aplica hacia el exterior (no hacia el interior)
- [x] Muro terminado en `A-MURO` (continuous/white/0.30mm)
- [x] Sin preguntas intermedias (offset automático 0.15)
- [x] Polilínea original se conserva (cara interior)

## Fase B — Vano con _break (actual)

### Algoritmo

```
1. (viene de Fase A: plineEnt + offsetEnt)
    │
2. Preguntar: "Agregar vano? [S/N] <S>:"
    ├── N → fin
    └── S → flujo vano:
            │
3. Usuario cliquea punto en el muro
    │
4. Usuario elige medida: 80 / 90 / 100
    │   (vano = medida + 6 cm para futuro marco)
    │
5. Para cada polilínea (interior y exterior):
    ├── vlax-curve-getClosestPointTo (punto clicado)
    ├── vlax-curve-getDistAtPoint → distancia sobre la curva
    ├── Calcular innerB1 = dist - halfWidth (con wrapping)
    ├── Calcular innerB2 = dist + halfWidth (con wrapping)
    └── vlax-curve-getPointAtDist → coordenadas de quiebre
    │
6. _break _F en ambas polilíneas (comando nativo AutoCAD)
    │
7. Obtener startPoint / endPoint de cada polilínea (ahora abiertas)
    │
8. Conectar por proximidad: innerStart→outerStart + innerEnd→outerEnd
    │   (si innerStart está más cerca de outerEnd, cruzar)
    │
9. Hecho — vano abierto, puntas conectadas
```

### Comandos AutoCAD utilizados

| Paso | Comando | Argumentos |
|------|---------|------------|
| 6i | `._break` | plineEnt, `_F`, pt1, pt2 |
| 6e | `._break` | offsetEnt, `_F`, pt1, pt2 |
| 8 | `._line` | punta interior, punta exterior, "" |

### Consideraciones técnicas

- **Wrapping**: si `innerDist - halfWidth < 0` o `innerDist + halfWidth > totalLen`, se suma/resta `totalLen` para mantener la distancia dentro del rango de la curva cerrada
- **Longitud total separada**: cada polilínea (interior y exterior) tiene su propia `totalLen` porque el offset de 0.15 agranda ligeramente la exterior
- **Break con `_F`**: se usa `_F` (first point) para especificar explícitamente ambos puntos de quiebre, evitando ambigüedad en la selección de entidad
- **Proximidad para conectar**: como el break puede invertir el orden de start/end, se conecta por cercanía (`distance`) en vez de asumir dirección

### Medidas de vano

| Opción usuario | Vano (`doorWidth + 6`) | halfWidth |
|----------------|------------------------|-----------|
| 80             | 0.86                   | 0.43      |
| 90             | 0.96                   | 0.48      |
| 100            | 1.06                   | 0.53      |

### Determinación de punto exterior (compartido con Fase A)

Centroide de la polilínea original → perpendicular al primer segmento → probar dirección opuesta al centroide → ese es el lado exterior para el offset.

## Fase C — Offset por segmento con selección visual (siguiente)

### Algoritmo

```
1. _pline interactiva (usuario dibuja, cierra con C)
    │
2. Preguntar: "¿Mismo espesor para todos? [S/N] <S>:"
    ├── S → offset uniforme (Fase A)
    └── N → flujo interactivo:
            │
3. _explode polilínea → N líneas individuales
    │
4. Para cada segmento i (N iteraciones):
    ├── _select / highlight entidad i
    ├── Mostrar: "Marque el segmento con clic" (confirmación)
    ├── _offset espesor elegido → punto exterior (basado en centroide)
    │
5. Borrar líneas originales explotadas
    │
6. _fillet R=0 entre cada par de líneas offset adyacentes
    │
7. Hecho — muros en A-MURO
```
