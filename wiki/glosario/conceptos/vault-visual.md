# Vault visual

> Imitar el concepto del vault (guardar → indexar → consultar → mejorar) pero con FOTOS e imágenes: capturas, Pinterest, redes, fotos de obra y maquetas. Cada imagen con contexto (quién, dónde, por qué se guardó) para que sea consultable en vez de un carrete muerto.

## Qué es

Extensión visual del [[wiki/glosario/conceptos/cerebro-digital-karpathy|cerebro-digital Karpathy]]: el mismo loop raw → wiki, pero la unidad no es texto sino imagen con metadatos (origen, fecha, proyecto, decisión que ilustra, estilo que referencia). Nace del pedido de Emília (titular no-técnica que piensa en imágenes) y se prototipa en el sprint STUDIO OS con el caso Casa masterplan: fotos + capturas + Pinterest como vault consultable de estilos de representación para presentar a clientes.

## Cómo funciona

1. **Ingesta:** foto/captura/Pinterest → carpeta del proyecto (`activos/`) + ficha mínima (origen, qué muestra, para qué sirve).
2. **Curaduría sí/no:** el titular aprueba (como el flujo IA: investigar → curar → renderizar) — lo no aprobado queda como negativo documentado.
3. **Consulta:** "mostrame cocinas toscanas con piedra" devuelve imágenes propias + referencias, no un scroll infinito.
4. **Mejora:** lo usado en entregas se marca; lo no usado 90 días se archiva.

Piloto: 3 estilos Casa masterplan. Regla: sin ficha no entra (igual que sin transcript no hay vault).
