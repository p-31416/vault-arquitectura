## 3. Decisiones punto por punto — revisión 2026-11-01

- ComfyUI por API como vía principal, CLI para debug, cloud como excepción (Comfy Cloud demo + Runpod Secure solo derivado).
- Flujos: primero los del concurso (txt2img, img2img croquis, ControlNet, 3D a imagen), después custom complejos.
- Rhino: puente actual + Hops, con evaluación 8 vs 9 antes de T3. Rhino.Compute como candidato R2.
- BIM: FreeCAD + IfcOpenShell. Bonsai queda para ciclo posterior con IFC real.
- Entradas MVP: croquis, volumetría, texto, voz, imagen referencia.
- Visualización: Unreal a futuro. Twinmotion acompaña como asistido cuando el piloto lo pide.
- Secretaría todo junto: Telegram + reuniones + agenda + métricas.
- Escala: MVP con Sol técnica + 1 persona arq, arquitectura pensada para mediana escala.
- Guardado: estas 3 rutas con `s` otorgada.
