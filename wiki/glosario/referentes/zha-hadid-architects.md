# ZHA — Zaha Hadid Architects

**Ubicación:** Londres | **Fundación:** 1979 | **Equipo:** ~500

Estudio más avanzado en IA a nivel global. Ver [[wiki/glosario/referentes/ia-estudios-internacionales|IA en estudios internacionales]] (global).

## Cómo usan IA

- Ideación: DALL-E, Midjourney, Stable Diffusion — 10-15% de salidas pasan a 3D
- Optimización planta: ML interno CODE research group
- Base de datos: NVIDIA NIM + LoRA + Stable Diffusion sobre archivo décadas ZHA
- Render: NVIDIA Omniverse + RTX, modelos locales para PI

## Unidades

- ZHAI (Analytics and Insights), CODE (co-fundado Shajay Bhooshan), colaboración NVIDIA

## Rol meta arquitecto en el estudio

ZHAI / CODE encarnan el rol [[wiki/glosario/conceptos/meta-arquitecto|meta-arquitecto]]: grupos dedicados que prototipan IA sobre archivo histórico y NVIDIA Omniverse como sistema que produce arquitectura.
