## 1. Objetivo

Cerrar una lamina master de **1000x700mm apaisada** (ratio 1.428, casi A1 apaisado 841x594 ratio 1.416) que luego se exporta a A1 oficial sin re-maquetar, con textos en ingles, tipografia disenada por el estudio y composicion segun referentes visuales.

Entregables:

1. `proyectos/concurso-gaudi-nexus/lamina/copy-en.md` — glosario EN fijo + bloques de texto.
2. `proyectos/concurso-gaudi-nexus/lamina/grid-1000x700.md` — reticula, zonas y jerarquia.
3. `activos/web/lamina/index.html` — espejo versionable para export a JPG ≤15MB.
4. `12345.jpg` final + `12345_design.jpg` A4 pieza mobiliario.

## 3. Herramientas + IA para diseno grafico

| Fase | Herramienta | Para que |
|---|---|---|
| Referentes | PureRef | tablero siempre-on-top con 6-10 laminas ganadoras |
| Composicion manual | Figma (recomendado) / Affinity Publisher / InDesign | grid 12 col, estilos de texto, import font propia |
| Version vault | HTML/CSS espejo | grilla + copy-en + imagenes por ref, export reproducible |
| Export | script `scripts/export-lamina.py` (a crear con `s`) | JPG calidad 90, chequeo ≤15MB, sello nº orden |
| Fondo IA con hueco texto | Adobe Firefly Image 5 / BFL / Flux | generar fondo con `negative space` reservado para titulo |
| Texto corto en imagen | Recraft V4.1 / Ideogram 4.x | titulares y etiquetas dentro de imagen, luego se re-rotula final fuera |
| Vector editable | Recraft Vector (SVG) | diagramas, pictogramas, carteleria para escalar sin perdida |
| Layout asistido | Figma Make / Design AI + PosterVerse (HTML) | 3 variantes de grilla editables, no PNG plano |

Tipografia propia: subir `.otf/.ttf` a `activos/lamina/fonts/` + `@font-face` en HTML. Definir H1 / H2 / body / caption una vez.

### 3.1 Como usar IA grafica sin romper la lamina

Regla madre: IA genera fondo y diagramas, el texto final siempre es texto nativo editable.

1. **Fondo con hueco:** prompt con composicion incluida, ej `plaza at dusk, subject right, open sky left for headline, no text, no logo`. Asi Firefly / Flux deja aire para titular. Si sale ocupado, Generative Expand para abrir aire.
2. **Recraft vs Ideogram:**
   - Recraft V4.1 = gusto + vector SVG editable, ideal diagramas y carteleria. Texto corto y medio bien, largo deriva.
   - Ideogram 4.x = bounding boxes + JSON layout, ideal titular + bajada + creditos colocados por coordenadas. Raster 2K, tipografia multifuente.
   - Lamina con fechas, listas, infografia densa: GPT Image 2.5 Sunburst es mas fiable que ambos para texto largo exacto.
3. **Figma AI:** Make genera 3 direcciones con auto-layout y estilos del estudio usando tu font, Replace content + Rename layers para limpiar. Todo queda editable, no es imagen plana.
4. **PosterVerse (paper 2026):** blueprint LLM + fondo diffusion + render HTML final. Es exactamente nuestro espejo HTML: fondo ComfyUI + textos nativos 100% fieles, escalables y re-editables. Adoptamos esa separacion.

Flujo: fondo IA (ComfyUI/Firefly/Flux) → layout Figma/HTML con font propia → diagramas vector Recraft SVG → export JPG. Nunca texto quemado en PNG.

## 6. Flujo de trabajo

1. Curar keepers desde `00-matriz-pruebas-concurso` (una variable por corrida, veredicto Sol).
2. Componer en Figma segun referentes, con grid y estilos.
3. Espejar a HTML + copy-en congelado.
4. Export JPG + chequeo peso + metadatos limpios de autor.
5. Revision contra `criterio-jurado` (6 criterios) antes de subir.

## 9. Riesgos

- Texto IA deforme: mitigacion componer fuera de ComfyUI, texto final siempre nativo Figma/HTML.
- Recraft largo deriva en listas/fechas: usar GPT Image 2.5 Sunburst para bloque denso o rotular fuera.
- Peso >15MB: export 150dpi calidad 90 + downscale hero si excede.
- Tipografia sin licencia: solo usar font propia en `activos/lamina/fonts/`.
- Anonimato roto: metadatos EXIF limpios antes de subir.
