# Lamina A1 — mock $0

> Master: A1 apaisado 841x594mm. Todo gratis: sin suscripciones, sin APIs pagas, sin fonts pagas.
> Mock visual: `activos/web/lamina-A1/index.html` (abrir en browser, offline).
> Plan madre: [[specs/261112-plan-lamina-1000x700|plan lamina]].

## Como funciona (mock)

1. Fondos: ComfyUI local RX 570 (RealVisXL Lightning 4-6 pasos) o Pollinations `flux.1-schnell` gratis.
2. Texto: siempre nativo HTML/Figma con font OFL (Inter / Space Grotesk). Nada quemado en PNG.
3. Diagramas: SVG inline gratis (Inkscape o Recraft free si alcanza).
4. Export: captura browser a JPG + compresion a ≤15MB con herramientas gratis (Squoosh / Pillow local).
